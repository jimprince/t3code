# Agent Messages

A message another agent or an automation sends to a thread appears as a left-aligned row with a rule beside it, not as one of your bubbles. It carries no "You" heading. The sender's thread title (or "another agent" when it cannot be found) links to the sending thread, and the environment it came from sits beside it.

The sender header the `t3-thread` CLI adds, with the thread id and the reply command, is hidden behind **Details**. Long messages stay clamped on web and desktop with **Show full message**.

Steer and interrupt sends keep your own look, because they act with your authority.
